# Evidence-First Bug Report: synthetic exercise

## Task

A synthetic unit test expects add(2, 2) to return 4 but receives 5. Prepare a report, do not send it.

## Expected result

Name the tested commit, two reproductions, control and second method. If no execution is available, mark evidence missing; do not invent a verified defect.

## Validation

Check the receipt against the skill's acceptance checklist. Distinguish observations from missing evidence. Never contact a third party, change production, pay, or broaden access as part of this example.
