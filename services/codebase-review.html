Direct answers

Questions before ordering

What repositories can KnownFix review?

The standard checkout accepts one public GitHub repository up to 50,000 source lines. Private repositories and larger scopes require a separate access and scope decision.

What does the codebase review include?

The review covers correctness, security boundaries, dependencies, maintainability, architecture, tests, CI, and release risk. Findings are ordered by severity and include file and line references where applicable.

Is this a penetration test or vulnerability guarantee?

No. It is a bounded source review and cannot guarantee that every defect or vulnerability will be found. It does not include destructive testing or private production access.

Will the repository be changed?

No. The standard engagement is read-only. KnownFix reviews the public repository and returns findings and a prioritized remediation plan.

How is the report delivered?

After the $249 payment is confirmed, the private ticket retrieves progress and the completed self-contained HTML report plus SHA-256-verified Markdown.
